## Screenshot Guidelines

- **Resolution**: 1920x1080 or higher
- **Format**: PNG or JPG
- **Quality**: High resolution, clear text
- **Content**: Show actual functionality, not mockups
- **Privacy**: Blur or remove any sensitive information

## How to Take Screenshots

1. **Desktop**: Use browser developer tools to set viewport to 1920x1080
2. **Mobile**: Use responsive design mode in browser
3. **Tools**: Use browser screenshot extensions or built-in tools
4. **Editing**: Use image editing software to crop and optimize

## File Naming Convention

- Use lowercase with hyphens: `feature-name.png`
- Be descriptive: `client-project-list.png`
- Include state if relevant: `verifier-pending-verifications.png`
